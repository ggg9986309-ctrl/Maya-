MAYA ₹20 MINI WEBSITE
=======================

Files:
- index.html
- style.css
- script.js

Deploy on Render:
1. Create a GitHub repository and upload these 3 files to the root.
2. On Render, choose New + Static Site.
3. Connect the GitHub repository.
4. Build command: leave blank
5. Publish directory: .
6. Deploy.
